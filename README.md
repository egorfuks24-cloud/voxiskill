# voxiskill

Автор: **creatorix**.

Навык для Codex: редакционные видео, где **оживают отдельные объекты и слои внутри кадра**, а не перелистываются целые картинки. Извлечён из производства исторической и Red Noir серий. Не официальный продукт VOX и не обучение весов модели.

## Что делает

- Уточняет тему, аудиторию, язык, стиль, голос, титры и бюджет, не повторяя уже данные ответы.
- При необходимости изучает нишу, проверяет факты, пишет хук и связный сценарий.
- Планирует самостоятельные сцены и причинные действия; разделяет изображения на фон, предметы, персонажей и передний план.
- Собирает движение кодом, синхронизирует с финальным голосом, добавляет читаемые титры.
- Проверяет результат и отдаёт видео с исходниками. Не обещает RPM, удержание или монетизацию.

Языки: английский, немецкий, французский; другие по фактическим возможностям среды. Базовый формат для выбора — 9:16, 65–70с, 30fps. В комплекте два цветовых примера; они не выбираются автоматически.

## Установка и запуск

Скопируйте **только папку `vox-animation`** в каталог навыков своего Codex (`$CODEX_HOME/skills`, обычно `~/.codex/skills`). Не заменяйте другие навыки. Если уже установлен `vox-frame-first`, выберите один основной навык для ролика — не запускайте два одинаковых процесса одновременно.

Пример запроса в новом чате:

> Используй $vox-animation. Сделай немецкий ролик на 67 секунд об Эмсской депеше. Нужны многослойные сцены, активное начало и пословные субтитры. Сначала уточни стиль и голос. Новые платные запросы пока запрещены.

Сам файл SKILL.md не генерирует видео: нужен агент с доступом к файлам, проверке источников, разрешённым изображениям и озвучке. Для локального рендера — Python 3.10+, Pillow, FFmpeg/ffprobe. Скрипты не устанавливают зависимости и не делают сеть. Установку выполняйте явно в своей среде. Шрифты и API-доступ не входят в архив.

## Комплект

`vox-animation/SKILL.md` — процесс; `references/` — драматургия, слои, голос/титры, качество/расходы; `assets/presets.json` — примеры палитр; `scripts/` — локальная сборка кадров, титры SRT и техническая проверка MP4. Рендер отдельных кадров создаётся агентом под историю, универсальная сетка из одинаковых карточек намеренно не включена.

В этом репозитории нет личных фото, видеоархивов, ключей, серверной конфигурации, cookies, подписанных URL или файлов аккаунта. Нет автоматической публикации и платных вызовов. При подготовке нового проекта храните секреты вне публикуемой папки.

## Локальные инструменты

После создания агентом кадров `frame-000000.png`, `frame-000001.png` и далее:

```sh
python3 vox-animation/scripts/render_frames.py frames output.mp4 --fps 30 --audio voice.wav
python3 vox-animation/scripts/captions_srt.py timings.json captions.srt --max-words 3
python3 vox-animation/scripts/verify_video.py output.mp4 --width 1080 --height 1920 --min-seconds 65 --max-seconds 70 --require-audio --samples-dir review
python3 -m unittest discover -s tests -v
```

Размер и длительность в примере замените на согласованные. Выходные файлы не перезаписываются. Формат `timings.json`: `{"segments":[{"start":0,"end":1.5,"text":"Eine Geschichte."}]}` или `{"words":[{"start":0,"end":0.4,"word":"Eine"}]}`. Это уже выровненные таймкоды, не приблизительная разметка по длине текста. Стиль и прожиг титров реализуются в рендере истории; SRT хранит текст и время.

Проверки выпуска: четыре автоматических теста прошли, включая реальное кодирование и полное декодирование двухсекундного тестового MP4 со звуком. Проверены ссылки и структура пакета. Это не тест художественного качества нового ролика и не независимый запуск навыка в новом чате. Штатный `quick_validate.py` недоступен в текущей среде из-за отсутствия PyYAML; выполнена отдельная проверка простой структуры frontmatter и локальных ссылок.
