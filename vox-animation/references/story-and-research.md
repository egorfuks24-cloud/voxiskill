# История, ниша, хук

Ниша — повторяемая потребность аудитории; тема и один вирусный ролик не равны нише. Для новой ниши ориентир выборки — 3–5 аккаунтов, 15–30 релевантных роликов разных уровней успеха. Это рабочий ориентир, не доказательство репрезентативности. Если доступно меньше, укажи фактический объём; не обходи доступ и не считай капчу просмотренным аккаунтом.

Сохрани URL, автора, даты публикации/проверки, язык, длину, видимые метрики, хук, вопросы аудитории и визуальную механику. Не выдумывай скрытое удержание, географию или доход. RPM из публичных просмотров не вычисляется. Новые правила монетизации проверяются по официальным актуальным источникам, не по старой цене в скилле.

Досье: сигналы спроса и контрпримеры, риски, 10 самостоятельных идей, ограничения доступности и производства. Изучение конкурентов не разрешает копировать их сценарии или медиа. В подтверждённой нише не повторять всю выборку при каждой серии.

Факт-лист: утверждение → источник → факт/интерпретация/неопределённость. Предпочитать первичные документы, музеи, научные/официальные публикации; спорный факт сверить независимо. Не смешивать эпохи, государства, роль свидетеля/подозреваемого/осуждённого. Для true crime: не романтизировать убийцу, не выдавать признание за подтверждённое дело, шифр за доказанную личность, условный рисунок за архивный материал.

Три возможных хука: парадокс, предмет-улика, выбор с неожиданной ценой. Каждый содержит реплику, действие первого кадра и обещанный ответ. Выбрать один. Не писать абсолютные «никогда», если история этого не доказывает; не разжигать ненависть между народами ради клика.

Ориентир минутного сценария: 0–3с конкретное событие/обещание; 3–12с минимум контекста; 12–30с причинная цепь/улика; 30–50с последствие/поворот; 50–63с ответ и оговорка; финал по выбранному CTA. Это структура для адаптации, не сетка, ради которой режут речь.

Обычно начать с 135–160 слов, затем измерить настоящую озвучку. Одна мысль на фразу, естественный синтаксис выбранного языка. Не растягивать текст пустыми повторами. Удержание — гипотеза: открытый вопрос → новая улика → изменение ожидания → ответ; не утверждать измеренные результаты до реальной аналитики.

Карта сцен содержит реплику, источник факта, главный объект, действие, видимое последствие, неподвижные слои, акцент и переход. Визуал должен объяснять тезис, а не конкурировать с голосом.
