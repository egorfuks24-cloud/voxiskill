# Кадр и причинная анимация

## Подготовка

Начать с выбранных материалов/палитры и самостоятельных кадров. Для нового сюжета составить манифест: ID, файл, роль, глубина, размеры, источник/права, персонаж и ограничения. Не переносить одного подозреваемого в роль следователя, сантехника или жертвы. Повторный объект допустим, если показывает новый этап, а не заменяет новую сцену.

Порядок глубины: чистый фон → архитектура/контекст → персонажи/предметы → главный объект → передние перекрытия → смысловая графика → титры. Под вырезкой должен быть восстановленный фон; тень движется вместе со слоем. Жёсткие лица не морфятся случайно. Отдельные части тела требуют корректных осей, масок и поз; зеркалирование не всегда допустимо для текста/направления действия.

Историческая серия и Red Noir из presets — альтернативные примеры, не универсальная внешность. Не добавлять случайные цвета, инфографику или предметы для заполнения пустоты. Не распределять один небольшой набор новых картинок по десяти почти одинаковым роликам: перед серией проверить разнообразие композиций и манифестов.

## Первые 30 секунд

Обычно 5–6 разных зрительных ситуаций, примерно 6–7с на ситуацию, с более коротким хуком. Смена главного объекта/пространства/действия, а не только заголовка/зума. Внутри ситуации запланировать действие → реакцию → изменённое состояние. Нет фиксированного магического числа анимаций и обещания +15% удержания от количества слоёв.

Просмотреть storyboard без текста. Если соседние сцены выглядят одной картинкой, перестроить до полного рендера. Для начала проверить весь интервал 0–30с, не только 1с и стыки. Не засчитывать бесконечный wiggle/параллакс как причинное событие.

## Рецепты по смыслу

- **Редактирование сообщения:** две половины ножниц вокруг общей оси; отрезанный фрагмент отделяется после закрытия, падает с ускорением; остальной текст остаётся.
- **Карта:** фиксированные координаты, линия раскрывается по длине, камера следует маршруту; исторические границы проверены. Схематический маршрут явно не выдаётся за географию.
- **Досье:** предмет открывает карточку → данные связываются с человеком → дополнительная проверка. Улика не мгновенно превращается в обвинительный приговор.
- **Архитектура:** створка закрывает вход/стена перекрывает проход; передняя рама перекрывает героя, создавая глубину. Слой не проходит через стену.
- **Сравнение:** два состояния рядом, один проход лупы, подсветка реального отличия. График только по данным, либо явно условная поясняющая схема.
- **Печать/письмо:** предмет один раз проходит маршрут, печать садится в точку; связанный слой реагирует. Не летает вся сцена.
- **Передача между сценами:** общий предмет/направление движения связывает конец и начало; match cut, локальная маска или короткое растворение. Не перелистывание каждого кадра.

Для спокойного однократного перемещения: p=clamp((t-start)/(end-start),0,1); q=6p⁵−15p⁴+10p³. Для падения — ускорение; для удара — короткая реакция. Не заставлять все события использовать одну кривую.

Параллакс поддерживает причинное событие: различная глубина, небольшое согласованное смещение, контактные тени и реальные передние перекрытия. Не заменять весь ролик полётом камеры между плоскими карточками. При растворении заголовки лучше рисовать отдельно от смешиваемых сцен, чтобы не получить двойной текст.

## Конкретный рендер

Агент создаёт под историю код `frame(t)` и импортирует разрешённые слои. Кешировать масштабированные изображения/шрифты, не запускать LLM на каждый кадр. Все кадры одинакового размера, последовательные имена. `render_frames.py` затем кодирует их с финальной дорожкой. При большом количестве кадров предпочтителен поток в FFmpeg; не выдавать кодировщик за универсальный генератор сцен.

Проверка действия: до → середина → после, роль и геометрия предметов, фон под ними, граница кадра, направление движения, титры. После изменения сцены заново проверить именно изменённую область.
