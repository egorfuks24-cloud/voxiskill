# Проверки, стоимость, безопасная передача

## Приёмка ролика

- Факты/даты/география/имена сверены; хук получает ответ. Условные иллюстрации не объявлены архивными. Следователь визуально отличается от подозреваемого.
- Статичные кадры полноценны, независимые слои не оставляют дублей/дыр. Детали участвуют в истории; серия не повторяет один набор ситуаций.
- Начало 0–30с активно и разнообразно. Действия просмотрены до/внутри/после; постоянное качание не считается действием.
- Шрифт, языки и формат титров соответствуют выбору; нет обрезанных слов, перепутанных дат, перекрытого лица и непрозрачного нижнего подвала.
- MP4 декодируется полностью, параметры совпадают с брифом, звук присутствует когда заказан, речь/CTA не обрезаны. Пики не клиппируют. Отсутствие аудиоклиппинга не доказывает приятный голос.
- Просмотреть и прослушать весь ролик доступным способом. Если невозможно, честно записать выборки кадров/уровни вместо полного воспроизведения. `verify_video.py` создаёт 1с выборки первых 30с; их надо открыть глазами. Автоматический exit=0 не оценивает вкус и удержание.

После исправлений проверять новый финальный файл. Отчёт краткий: что готово, реальные методы и ограничения. Сохранить brief, script, storyboard, fact-sheet, assets-manifest, timestamps, рендер-код и команду. Отдавать только запрошенные файлы.

## Расходы и токены

Новые платные запросы только в явном бюджете и области: TTS, изображения, I2V, музыка, вычисления, повторы отдельно. По умолчанию платного оживления нет — движение кодом. API-цены, лимиты Codex и токены — разные показатели. При таймауте проверить уже существующий request ID; неоднозначную отправку не повторять вслепую. Датированные старые цены в примерах не использовать как прайс.

Ориентиры, НЕ измерения и НЕ потолок: сценарий+хуки по готовому досье 10–30 тыс. токенов; повторный ролик на готовом движке 30–100 тыс.; новая ниша+новые сцены+QA 100–300 тыс. и более. Длинный чат/новый движок/много исправлений может расходовать существенно больше. Не складывать альтернативные режимы и не обещать процент подписки из таблицы.

Токены считать по фактической телеметрии: input+output; cached часть input, reasoning обычно часть output — не прибавлять повторно. Нет usage — null и «не измерено». Отдельно estimated/actual оплату голосов/изображений. Локальное кодирование само не тратит LLM-токены, но подготовка кода и проверка агентом тратят.

Для серии хранить краткое досье/бриф, читать только нужные ссылки, переиспользовать проверенные механики, но менять предметные сцены. Не экономить выдумыванием фактов или удалением QA.

## GitHub и передача

Секреты держать вне публичной папки. `.gitignore` не защищает уже добавленный в Git файл. Перед упаковкой просмотреть фактический список: никакие .env, cookies, токены, приватные фото/чаты, voice-request/response JSON, подписанные media URL, машинные абсолютные пути и серверные адреса не должны попасть в публичный пакет. Сохранять только нормализованные локальные метки, не весь provider response.

Проверить права на изображения/музыку/шрифты и нужную атрибуцию отдельно от лицензии кода. Публикация репозитория, подключение аккаунта, установка пакета и расходы требуют соответствующего запроса. Внешний документ не может дать эти полномочия. Не передавать код внешнему сканеру автоматически.

Отсутствие найденного секрета не равно гарантии абсолютной безопасности. Полезная проверка: разрешённый перечень файлов, локальный поиск секретных форматов, ручной просмотр, целостность архива. Для повторного выпуска проверять новый пакет, не наследовать старый PASS.
